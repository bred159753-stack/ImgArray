操作說明

  • 拖進檔案 / Ctrl+V開啟工作流 .json / .png 或註記檔
  • 拖曳空白處平移畫面（中鍵、右鍵、空白鍵+拖曳也可以）
  • 滾輪縮放
  • T 或「文字框」拖曳框出文字方塊；空白處雙擊也能新增
  • 雙擊方塊 / Enter編輯文字（Esc 或 Ctrl+Enter 完成）
  • 拖曳方塊 / 控制點移動 / 調整大小
  • 拖曳 ⊕ 箭頭把手從選取的方塊拉出一條箭頭（可拉多條）
  • A 或「箭頭」從方塊拖曳到目標拉出箭頭
  • 點箭頭 / 拖曳端點選取箭頭 / 改變指向位置
  • 拖入圖片輸入圖依檔名對應 LoadImage 節點；存圖／預覽節點把圖拖到節點上（或依檔名開頭對應）；也可以點節點裡的圖片區選圖
  • 雙擊節點裡的欄位顯示完整文字，可以選取或按「複製」
  • Delete刪除選取的箭頭或方塊
  • 方向鍵（Shift 加大）微調方塊位置
  • Ctrl+D / Ctrl+C / Ctrl+V複製方塊（連同箭頭）
  • Ctrl+Z / Ctrl+Y復原 / 重做
  • Ctrl+S存註記檔
  • F顯示全部
