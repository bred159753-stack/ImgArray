01 載入圖片

也可以直接把圖片拖進中間畫布，或 Ctrl+V 貼上剪貼簿圖片。

02 框選設定

03 選取的框

先點一下選取，再拖曳框內可移動、拖曳八個控制點可調整大小；Ctrl+D 或 Alt+拖曳可複製。

04 陣列複製

先框好左上角第一格並選取它，填入欄數（橫向）、列數（直向）與格子之間的間距（可為負數）。游標移到這區時，畫布會用紫色虛線預覽。

05 AI 建議框

建議框以青色虛線顯示，雙擊建議框即可採用成正式框；和現有框重疊的建議會自動隱藏。第一次使用需下載模型（約 150 到 450MB），之後瀏覽器會快取。

06 匯出

框設定 (JSON) 可存起來，同版型的圖下次直接讀入套用。

操作說明

  • 空白處拖曳新增框
  • 點一下框選取（重疊時連點會輪流切換）
  • 拖曳已選取的框移動框
  • 在未選取的框上拖曳在框內畫新框
  • 控制點拖曳調整大小（Shift 鎖比例）
  • Alt + 拖曳框複製並移動
  • Ctrl + C / V複製、貼上框
  • Ctrl + D原地旁複製一個框
  • 方向鍵移動 1px（Shift 10px）
  • Ctrl + 方向鍵調整寬高 1px（Shift 10px）
  • Delete刪除選取的框
  • Ctrl + Z / Y復原、重做
  • 滾輪以游標為中心縮放
  • 空白鍵 / 中鍵 / 右鍵拖曳平移畫布
  • Esc取消選取
  • 雙擊青色建議框採用 AI 建議框
