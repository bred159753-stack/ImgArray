無限畫布圖片編輯器 Tool 5

01 載入圖片 / PSD

讀取的圖片會同時放上中間畫布，並累加到右邊的「當前庫內圖檔」；之後也可以從圖檔庫再拖曳（或雙擊）放上畫布。PSD 會先讓你勾選要讀取的圖層，放上畫布時保留原本的相對位置。也可以直接把檔案拖進畫布。
這個工具不會存檔，關閉分頁後就會消失，需要的成果請用「輸出框線」存下來。

02 工具

框線是輸出範圍：選取框線後按「輸出框線」，可以輸出合成 PNG，或把範圍內的每張圖存成一個多圖層 PSD。

操作說明

  • 拖曳檔案到畫布匯入圖片／影片／PSD（可一次多個或整個資料夾）
  • 圖檔庫：點選 / Ctrl+點選 / Shift+點選選取 / 加選 / 連續選取多張
  • 圖檔庫：拖曳 / 雙擊把圖放上畫布（拖曳放在滑鼠位置，選取多張時一起拖；雙擊放在畫面中央）
  • 圖檔庫：Ctrl+滾輪縮放圖檔庫縮圖
  • 點選 / Shift+點選選取 / 加選、取消
  • 在空白處拖曳框選
  • 拖曳角落控制點等比縮放（Alt：以中心縮放）
  • 拖曳上方圓點旋轉（Shift：每 15° 吸附）
  • 中鍵／右鍵／空白鍵+拖曳平移畫面
  • 滾輪縮放（觸控板雙指為平移，捏合為縮放）
  • 方向鍵（Shift 加大）微調位置
  • Ctrl+方向鍵往該方向對齊：上下（或左右）有重疊的圖會依序靠攏，距離 = 對齊間距
  • 等高／等寬自動排列統一高度橫排（上下緣對齊），或統一寬度直排（左右緣對齊）
  • Ctrl+A / Delete全選 / 刪除
  • Ctrl+Z / Ctrl+Shift+Z復原 / 重做
  • T 或「T 文字」在畫布上點一下輸入文字；Ctrl+Enter 或點別處完成
  • 雙擊文字 / Enter重新編輯文字；「文字顏色」改顏色，拖角落改大小
  • R 或「框線」拖曳拉出框線；有選取作品時直接包住選取範圍
  • 拖曳框線角落自由調整框線大小（Shift 維持比例）
  • 點框線邊緣 / 名稱選取框線（雙擊可改名，名稱就是輸出檔名）
  • 輸出框線PNG：合成成一張圖；PSD：範圍內每張圖一個圖層
  • Ctrl+D / Ctrl+C / Ctrl+V複製 / 拷貝 / 貼上（貼在滑鼠位置）
  • ↔ ↕ 間距顯示目前間距，? 表示不一致；輸入數值套用
  • 0 / F顯示全部 / 聚焦選取
  • 雙擊圖片 / 影片放大到該圖片 / 播放影片
